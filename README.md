# 🌿 幻将棋 Genshougi

オリジナルルールの将棋ゲームです。AIたいせん・友達たいせん（2人プレイ）に対応しています。

## こまの一覧

| こま | うごき | スキル |
|------|--------|--------|
| 👑 おうさま | うごけない（🐴ごそう時のみ） | なし |
| 🛡️ まもり | まわり8方向 1マス / 常時：💣たいほうをはじく | なし |
| 🐴 うま | 前後左右 最大2マス（飛越不可） | ごそう：おうさまを前へ |
| 🦁 らいおん | 前後左右＋ななめ前2方向 各1マス | ほうこう：敵こまを前方に押す |
| 🐸 ぐしゃ | ななめ4方向 各1マス | てんい：味方こまを任意の場所へ（最奥列は不可） |
| 🐦 すずめ | 前2マス（まもり以外飛越可）＋左右1マス | なし |
| 💣 たいほう | 前後＋ななめ4方向の2マス先（飛越可・まもりは飛越不可） | ほうげき：相手の手駒を1枚除外 |

## ローカル開発

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。

## ビルド

```bash
npm run build
```

`dist/` フォルダに静的ファイルが生成されます。

## 公開方法（おすすめ）

### Vercel（一番かんたん）

1. [vercel.com](https://vercel.com) でアカウントを作る
2. GitHubにこのフォルダをリポジトリとして登録する
3. Vercelで「New Project」→ GitHubのリポジトリを選ぶ
4. そのまま「Deploy」を押すだけで公開完了！

### Netlify

1. [netlify.com](https://netlify.com) でアカウントを作る
2. `npm run build` を実行する
3. `dist/` フォルダをNetlifyにドラッグ＆ドロップするだけで公開完了！

### GitHub Pages

1. GitHubにリポジトリを作る
2. `vite.config.js` に `base: '/リポジトリ名/'` を追加する
3. `npm run build` を実行する
4. `dist/` の中身を `gh-pages` ブランチにプッシュする
